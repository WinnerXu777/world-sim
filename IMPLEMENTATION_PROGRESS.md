## Control protocol verification, 2026-09-06

The preceding goal turn made progress on saves and the menu. This continuation added protocol version 1 plus world/possession epochs to movement and event requests. Reclaiming even the same actor rotates possession identity. The runtime rejects stale identities, invalid sequence types, incorrect movement targets, and non-finite movement/look/aim values before changing controls.

Movement commands enter a maximum 64-command queue per possession. The simulation consumes them at its tick boundary and publishes `last_applied_input_seq` after processing; `last_input_seq` remains the received sequence for compatibility. ## Autosave and shutdown verification, 2026-09-06

The preceding turn made verified inventory-command progress. This continuation added an owned 60-second autosave task for selected gameplay worlds and a final checkpoint on normal backend shutdown. Shutdown stops ticks first, cancels/drains autosave (including its shielded disk worker), then saves the final tick under the same session lock. Unchanged ticks skip periodic saves.

# Personality Future

Current limitations:
- Personality is still mostly static after assignment
- Pressure appraisal is useful but still simpler than the long-term social-intelligence target
- Life events do not yet reshape personality deeply over time

Nuances:
- Personality already flows into goals, talk, escalation, and reasoning prompts, so changes here have large downstream consequences
- Traits should stay interpretable enough for debugging and prompt design

Suggested next elaborations:
- Add slow personality drift or trauma-based changes over time
- Deepen pressure categories for greed, loyalty, shame, pride, and fear
- Tie social memory and recurring success/failure into appraisal
- Expand talk-tone and planning bias usage without turning personality into hardcoded rules

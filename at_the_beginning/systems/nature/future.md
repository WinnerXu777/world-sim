# Nature Future

Current limitations:
- Environmental simulation is broad but still relatively coarse
- Localized weather, climate, and long-term biome dynamics are still shallow
- Disaster aftermath is simpler than the long-term world-story target

Nuances:
- Nature events are strong sources of memory, escalation, and future goal changes even if that wiring is not yet fully deep
- This module should stay world-facing and deterministic, not model-facing

Suggested next elaborations:
- Add stronger localized weather and region history
- Expand ecological feedback loops between animals, water, vegetation, and disasters
- Improve disaster aftermath and recovery systems
- Feed clearer event summaries into memory and talk systems near the player
